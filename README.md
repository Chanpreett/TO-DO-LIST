# 📝 To-Do List App

A simple To Do List app built with HTML, CSS and JavaScript.

## ✨ Features

- ✅ Add Tasks
- ✅ Delete Tasks
- ✅ Mark Tasks as Completed
- ✅ Enter Key Support
- ✅ Local Storage Support
- ✅ Progress Bar
- ✅ Day & Night Mode
